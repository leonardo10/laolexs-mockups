Pilihan Infrastruktur Server

Server dipetakan 1:1 ke paket yang dipilih (Alibaba Cloud) — jalur bertahap: Starter → Rekomendasi (+HA) → Roadmap (Kubernetes).

CEPAT
Starter

1 Simple Application Server (all-in-one): 1 VM App + 1 DB dalam 1 server (2 vCPU/4GB). Cocok MVP, budget ketat.

Rp 300.000 – 450.000 / bulan
MENENGAH
Rekomendasi (+ HA)

1 VM App terpisah + 1 server DB (RDS High Availability, primary+standby) — kelas Menengah/Ideal. Failover otomatis kalau DB utama bermasalah.

Rp 1.500.000 – 7.000.000 / bulan (Menengah–Ideal)
ROADMAP
Next Step: Kubernetes

Kalau traffic tumbuh melebihi kapasitas Ideal (2× ECS + RDS cross-AZ), langkah berikutnya migrasi ke Kubernetes terkelola (mis. Alibaba ACK). Bukan kebutuhan sekarang — dicatat sebagai arah masa depan saja.

Belum ada estimasi biaya — evaluasi saat dibutuhkan
Rekomendasi "start small": server development/staging (untuk UAT) sengaja dibuat KECIL (2 vCPU/2–4GB, ±Rp150rb–1jt/bulan) — cukup untuk pengujian sebelum rilis, bukan meniru kapasitas produksi. Upgrade dilakukan hanya kalau benar-benar dibutuhkan.
